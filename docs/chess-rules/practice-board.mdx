# Practice Board

Play through moves on the interactive board below. **Drag and drop** the pieces -
only **legal moves** are allowed, and the status line tells you whose turn it is,
when a king is in **check**, and when the game ends in **checkmate** or a **draw**.

<InteractiveBoard />

Use **Undo** to take back a move, or **Reset** to start over from the initial
position. Pawns reaching the last rank are automatically promoted to a queen.

## Try It Yourself

Set up the moves from the [Opening Principles](./opening-principles) page and watch
how the position develops, or replay one of the [Puzzles](./puzzles) to check that
your solution really works.

:::tip
This board enforces every rule in this guide - castling, en passant, promotion,
check, and checkmate - so it's a safe place to experiment while you learn.
:::
