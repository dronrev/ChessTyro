# Membaca & Menulis Notasi

**Notasi algebra** ialah cara piawai untuk merekod gerakan catur. Ia membolehkan anda
menulis sesuatu permainan, membaca buku catur, dan mengikuti gambar rajah dalam
dokumentasi ini.

## Menamakan Petak

Setiap petak mempunyai nama unik yang terdiri daripada **huruf fail**nya (a–h) dan
**nombor rank**nya (1–8). Fail berjalan dari kiri ke kanan dari sudut Putih; rank
berjalan dari Putih (1) ke Hitam (8). Bidak di bawah berada pada **e4**:

## Menamakan Buah

Setiap buah ditulis dengan satu huruf besar (berdasarkan nama Inggerisnya):

| Buah   | Huruf |
| ------ | ----- |
| Raja (King)    | K |
| Menteri (Queen)| Q |
| Tir (Rook)     | R |
| Gajah (Bishop) | B |
| Kuda (Knight)  | N (bukan K!) |
| Bidak (Pawn)   | *(tiada huruf)* |

## Menulis Sesuatu Gerakan

Gerakan ditulis dengan huruf buah diikuti petak destinasi:

- **`Nf3`** - kuda bergerak ke f3.
- **`e4`** - bidak bergerak ke e4 (bidak tiada huruf).
- **`Bb5`** - gajah bergerak ke b5.

## Simbol Istimewa

| Simbol | Maksud |
| ------ | ------ |
| `x`    | Menangkap (cth. `Bxe5`, atau `exd5` untuk tangkapan bidak) |
| `+`    | Sekak |
| `#`    | Sekakmat |
| `O-O`  | Rok sisi raja |
| `O-O-O`| Rok sisi menteri |
| `=`    | Naik pangkat (cth. `e8=Q`) |
| `e.p.` | Tangkapan en passant |
| `!` / `?` | Gerakan baik / kesilapan (ulasan) |

## Merekod Sesuatu Permainan

Gerakan dinomborkan, dengan gerakan Putih dahulu dan Hitam kedua:

```
1. e4 e5
2. Nf3 Nc6
3. Bb5 a6
```

Keputusan ditulis di hujung: **`1-0`** (Putih menang), **`0-1`** (Hitam menang),
atau **`½-½`** (seri).

:::tip Pembezaan
Jika dua buah serupa boleh bergerak ke petak yang sama, tambah fail atau rank
permulaan untuk menjelaskannya - contohnya `Nbd2` (kuda dari fail-b) atau `R1e2`
(tir pada rank 1).
:::
